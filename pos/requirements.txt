# pos/requirements.txt
# Pinned runtime dependencies for the VipePOS Windows printer listener.
#
# Version rationale:
#   python-socketio[asyncio_client]==5.11.4
#                         — socket.io client for the API namespace /realtime (print_job events);
#                           the asyncio_client extra pulls aiohttp.
#   aiohttp==3.10.10      — HTTP for GET /api/print/jobs/pending and POST .../ack; pinned
#                           because app.py imports it directly.
#   customtkinter==5.2.2  — CTk 5.x has breaking changes from 4.x; pin to avoid surprise.
#   pystray==0.19.5       — system-tray icon; 0.19.x is stable for Python 3.11.
#   Pillow==10.4.0        — image processing for ESC/POS rasterization.
#   html2text==2024.2.26   — converts HTML order payloads to plain text for printing.
#   escpos-python==1.0.2  — ESC/POS command builder; 1.0.x is the latest published on PyPI.
#   pywin32==306          — Windows API access (CryptProtectData, DPAPI credential store).
#                           Marker restricts install to Windows; the pos-deps-check CI runs
#                           on ubuntu-latest and would otherwise fail with "no matching
#                           distribution".
#   pyusb==1.0.2          — PyUSB; libusb1 backend for USB printer discovery.
#   python-dotenv==1.0.1  — loads .env in dev mode; 1.x is stable.
#   pyinstaller==6.10.0   — bundles app.py into a Windows .exe.
#
# Install:  pip install -r pos/requirements.txt
# Verify:   python -c "import customtkinter, pystray, PIL, html2text, escpos, win32crypt, usb, socketio, aiohttp, dotenv"
